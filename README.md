mend is a command-line tool that applies the edits AI models write — unified diffs,
SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of text files,
exactly as its specification says: every change, or none.

Run it as `node main.ts [options] [PATCH]` (Node 22, standard library only).
